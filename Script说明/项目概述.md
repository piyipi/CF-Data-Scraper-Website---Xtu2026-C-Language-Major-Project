# Codeforces Rating Crawler —— 项目概述

## 一、项目简介

**Codeforces Rating Crawler** 是一个命令行工具，利用 [Codeforces 官方 API](https://codeforces.com/apiHelp) 抓取用户的竞赛数据，对其比赛情况进行多维度统计分析，并通过 ECharts 实现交互式可视化展示。

输入一个 CF 用户名，程序自动完成数据拉取、统计计算、页面生成的全流程，最终输出一个可直接用浏览器打开的 HTML 页面，包含用户 Rating 曲线、难度直方图、比赛详情表格等完整的竞赛画像。

## 二、技术栈

| 层级 | 技术 | 作用 |
|------|------|------|
| 数据获取 | C + libcurl | HTTP GET 请求 Codeforces API |
| 数据解析 | cJSON（v1.7.18） | JSON 解析，将 API 响应转为 C 结构体 |
| 数据分析 | C（自研 analyzer 模块） | 补题匹配、近 180 天统计、难度分布直方图 |
| 数据导出 | C（fprintf 拼接） | 将分析结果导出为 JavaScript 变量文件 |
| 前端可视化 | HTML5 + CSS3 + ECharts 5 | 暗色主题页面，Rating 折线图 + 难度直方图 + 比赛表格 |

**开发环境**：MinGW-w64 (GCC 8.1.0) / Windows 10+

## 三、核心功能

### 基础功能
1. 读取用户 ID，调用 CF API 获取用户信息
2. 抓取比赛列表和用户参赛记录（排名、得分、各题分数）
3. 分析用户提交记录，自动识别赛后补题情况
4. 统计并展示：当前等级分、头衔、头像、总比赛次数、历史最高分、近 180 天比赛次数、近 180 天最高分
5. 用户 ID 按 CF 等级分对应颜色显示
6. 按时间从近到远展示所有比赛的详情表格（赛事名称、时间、分差、各题状态、补题列表）

### 选作功能
7. 多用户支持：读取用户 ID 列表文件，生成用户摘要表格（含排序 + 页面跳转）
8. 难度直方图：统计通过题目的等级分分布，支持「全部 / 近一年 / 近 180 天 / 近 1 月」四个时段切换

## 四、运行模式

| 模式 | 命令 | 输出 |
|------|------|------|
| 单用户 | `cf_crawler tourist` | `output/data.js` + `output/index.html` |
| 多用户 | `cf_crawler tourist Petr Benq` | 各自 `{handle}_data.js` + `{handle}.html` + 列表页 `index.html` |
| 文件模式 | `cf_crawler users.txt` | 同多用户模式（从文本文件批量读取 handles） |

## 六、设计特点

- **纯 C 核心**：数据抓取与统计分析全部用 C 实现，编译为单文件 exe，无需运行时环境
- **模板数据分离**：HTML 页面 = 公共模板 + 用户专属数据文件（data.js），修改样式只需改模板
- **容错设计**：单用户拉取失败不影响多用户模式中的其他用户；模板缺失时仍输出数据文件
- **自包含输出**：生成的 HTML 仅依赖 ECharts CDN，双击即可在浏览器打开
- **CF 原色系统**：用户昵称、等级分、图表节点严格按 CF 官方颜色体系着色（灰/绿/青/蓝/紫/橙/红/暗红）
