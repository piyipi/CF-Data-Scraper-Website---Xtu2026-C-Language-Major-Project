# Codeforces Rating Crawler —— 项目设计模式

本文档汇总项目中各模块使用的可复用设计模式和惯用法，按架构分层顺序记录。

---

## 第2层：http_client

### 模式 1：Init/Cleanup 配对 + 幂等保护

**所在函数**：`http_init()` / `http_cleanup()`

**模式描述**：
```
程序启动:  http_init()     → curl_global_init(CURL_GLOBAL_ALL)     // 仅一次
运行阶段:  http_get() × N  → curl_easy_init() / curl_easy_cleanup() // 每次请求都创建/销毁
程序退出:  http_cleanup()   → curl_global_cleanup()                  // 仅一次
```

**关键要素**：
- 静态标志 `g_initialized` 记录初始化状态，保证 init/cleanup 函数**幂等**（多次调用安全）
- `http_init` 检查标志 → 未初始化则执行，已初始化则跳过
- `http_cleanup` 检查标志 → 已初始化才清理，清理后重置标志
- libcurl 官方不保证 `curl_global_cleanup` 重复调用安全，这是本项目引入幂等保护的原因

**适用场景**：任何需要全局初始化/清理的 C 库封装（如 SDL、OpenSSL、SQLite），确保上层调用者不必关心调用次数和顺序。
